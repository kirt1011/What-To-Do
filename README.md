# What-To-Do
A simple To-Do list web app built using HTML, CSS, JavaScript, and Bootstrap.
🚀 Excited to share my latest project: What To Do? – A Modern To-Do List Application
I built this project to improve my frontend development skills using:
✅ HTML
 ✅ CSS
 ✅ Bootstrap 5
 ✅ JavaScript
Features
Add, Edit & Delete Tasks
Task Priorities (High / Medium / Low)
Due Dates
Search & Filters
Dark Mode
Drag & Drop Task Sorting
Progress Tracking
Local Storage Support
Fully Responsive Design
Live Demo
https://v0-to-do-list-app-eight-puce.vercel.app/
This project helped me practice UI design, JavaScript logic, local storage, and responsive web development.
Feedback and suggestions are welcome!
